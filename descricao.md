# 100 Projetos de Ciência de Dados

Cem projetos práticos para aprender ciência de dados fazendo, do CSV ao modelo e ao model card. Cada pasta traz um problema, o código, dados sintéticos e o comando para rodar na sua máquina.

A trilha tem dez categorias: fundamentos, análise exploratória, SQL, estatística e experimentos, feature engineering, aprendizado supervisionado, não supervisionado, séries e texto, avaliação/ética/MLOps e projetos completos. Dá para seguir a ordem ou escolher uma trilha no README. Python 3.11 basta para começar. Não há conta paga obrigatória.

O material é educacional, em português, com dados fictícios. Serve para praticar, montar portfólio e explicar uma decisão com código que roda. Não substitui um ambiente de produção.
